# Archived v0.16 origin design and profile schema

The v0.16 experimental standalone main-menu editor is discontinued after the user's screenshot of unreadable vertical labels and inaccessible Close controls. The current [native Sandbox flow correction](V017_NATIVE_SANDBOX_FLOW.md) removes this entry point and leaves the normal Sandbox wizard intact. The origin profile schema remains in source for the later integrated native steps.

The v0.16 prepared family fields, character statistics and starting resources **do not indicate working in-game family hero generation**. The redesigned flow still requires game-version-specific native stage insertion and real campaign save/load acceptance.
