# CU v0.74 campaign correspondence and affairs
24 November 2026. PR #100. The prior head 8c536ea0128d4cc13c82e87594cf729e8a062c9e passed run 45380982528. New source needs its own compile and native acceptance.

## Design
- One read-only correspondence journal, intended to open from a map bar tab, a map-side pending notice, and the established Clan/Party/Kingdom dossier correspondence action. The side notice is a persistent aggregate indicator (not a new native quest notification or intrusive popup). Clicking it opens the pending view. It is hidden when no matters await attention; opening does not dismiss actual obligations. Exact MapBar and MapNotification movie XPaths must be verified in the game.
- Tabs Pending, Letters, Service, Household, History. Five selectable rows per page; detail gives actual observed person/whereabouts, existing obligation and required in-person action. No remote conversation launch, payment, relation edit, troop transfer, estate grant or added save schema. The pending notice polls only bounded state once per second and releases its weak reference on game end. Full person lookup is performed on journal open, not per frame. A daily cached identity check excludes deceased or unavailable identities from due-follow-up alerts; active requests still follow the existing expiry rules. Current records refresh on reopening.
- Existing state is the authority: one actual pending request, eligible one-time petition follow-ups, active career charge, current sworn patron orders and due muster/audience, unresolved family claim, current sieges, owned holdings and officers. Resolved and no-longer-pending petitions go to history; not fabricated conversations. Native game handles all mutations. No extra rewards.
- Owned castle administration is now nested in the existing owned-holding hub, renamed Attend to local affairs. No separate top-level castle administration. Birth-family audience remains contextual; the Knight survey remains physically local. Duplicate instructional family audience removed rather than leaving a permanently disabled menu entry. Opening an old court/requests menu no longer manufactures a petition; daily initiative and real private conversation are authoritative. The prior family audience instruction about a relation reward was stale and corrected.
- A global fallback exists through the prior native Clan/Party/Kingdom dossier, and camp correspondence forwards to the same journal. The map patches are compiled against pinned reference assemblies but exact live movie placement, mouse/keyboard focus, other mods, 720p/1080p/wide layouts need tests.
