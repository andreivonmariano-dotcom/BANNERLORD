# SIM-001 | Independent Bannerlord research simulator
Original Python standard-library tools. No game install, no proprietary binaries or raw saves in repository. Not a replacement engine. Read-only reader restricted to observed v1.5.7.125802 framing; no typed object graph or arbitrary save editing. Model inputs: DUT-002, SAV-003, D001. Risk formula and two UI observations verified; simplified lifecycle, supplied outcome and synthetic snapshot are explicitly not native serialization. Commander assumed fit and surviving; no concurrent tasks, native cancellation, death, issue eligibility, random casualty model, map movement, or full economy. Failure handling is hypothetical simulation policy. Return blockers selected static native rules, not native tested. Seeded random sampling demonstrates risk only, not native RNG. Replay uses observed losses/wounds/reward; do not claim prediction. Residual gold is unmodeled rather than fitted. 
Run with existing Python (no pip): `py -3.14 -m unittest -v test_simulator`; `py -3.14 run_d001.py --save-dir "<Documents>/Mount and Blade II Bannerlord/Game Saves"`. The CLI reads only the three exact D001 names; no save modification. Run only outside game directory. Do not publish console output containing local/private identifiers. 
Research boundary: simulator test PASS is not Gate C-F or player acceptance. Future domain modules need exact engine evidence and independent native cross-checks. Before integration revalidate engine/provider hashes, full profile and player value.
