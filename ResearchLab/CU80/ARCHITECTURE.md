# CU80-ARCH-001 | Technical blueprint
26 November 2026. Candidate architecture, not runtime changes. Six system ownership preserved. Separate offline simulator/test harness from production. Runtime ZIP remains one Modules/CalradiaUnified, one CU DLL; no observer, lab scripts or simulator bundled.

## Boundaries and dependency direction
Native/approved provider -> read-only adapter -> immutable scoped snapshot -> pure policy selects situation/choices -> existing conversation presenter -> explicit player choice -> existing action adapter (one native command) -> fresh verified readback -> bounded confirmed memory -> existing Chronicle. Diagnostic evidence separate from player text. No native calls from pure policy, no game writes from observers, no mutable global per-NPC world simulation. No additional campaign listeners until exact necessity and lifecycle proof. Query local player/conversation/party on demand; bounded event updates for known milestones, not full-world scanning.
- Native context: campaign/session scope, player Hero.StringId, actual speaker, clan, party, settlement; known/unknown values separately; observed native tick/revision, active model/provider identity, six raw/effective roles, roster membership, wounded count, skill, current authority. No guessing unknown values or using saved snapshot as live authority.
- Situation policy: input only native facts and bounded pair history; returns typed reason, choices, evidence needs. Exclude irrelevant and impossible action. UI uses localized text and existing topic/dossier, not raw IDs.
- Command intent: immutable offer token scoped to session/player/actor/target/action; explicit accept; re-read before action; stale/unknown/unsafe blocked. One-shot consumed before invocation; do not auto retry ambiguous side effects. Bound in-session intent store; refuse when full rather than evict unresolved intent. Native poststate is authority. No synthetic balance, role, or independent consent. 
- Receipt: confirmed only exact identity and expected before/after plus untouched protected fields. Pre-event/callback is not transaction receipt (AUT-005). A native exception can leave partial effects; record unconfirmed, inspect, never blindly compensate. Cancellation/refusal no native call. A changed relation or balance alone is not proof of cause.
- Observation: after confirmed role, compare later valid snapshot with same identity, actual role, comparable roster composition, monotonic tick; wounded delta descriptive only, never a causal claim. Trade-gold discrepancy F057 prevents using projected party gold as hero balance. No forecast output as runtime fact (VAL-003, AUT-007). Provider predecessor unknown => no full formula.
- Memory: existing SandboxLifeHistoryState 64 people/192 bonds/96 events, exact pair and existing serialized keys; avoid new global persistent ledger until schema/migration review. First isolated code has session-local token state only. Production persistence design must reconcile in-flight intent and native state on reload; no replay or reuse token across load, no automatic retry after uncertain action. Existing role raw vacancy prevents repeat appointment; other irreversible financial commands require separately tested durable request identity and old-save migration. No new literal save keys in this prototype.
- Presentation: existing SandboxOriginBehavior.LivingDialogueDepth.cs topic path and NobleOfficerDialogues.cs appointment handler; reuse CanAssignHouseholdSpecialty/AssignHouseholdSpecialty rather than second setter. Need refactor handler to return structured verified result without changing native authority, retain existing diagnostics and current ordinary path. Existing memory Remember only on confirmed role; Chronicle reads fact. HouseholdDuties and PetitionConversations reviewed separately before any money integration. No forced Gauntlet screen.
- Testing: pure fake adapter with known identity/slots, eligibility/decline/stale/exception/replay/slot mutation/observation checks; isolated native adapter future only after source and installed contract check, safe save isolation. Player test before integration. Full stack 41 modules, four framework dependencies, old copied saves, all seven careers, 30 days and 60 min Gate F. No promotion on compile/test alone.
